Platform comparison

EcoPower 2.0 → 3.0

2.0 looked finished. In front of a jury of utility operators it had one fatal flaw: the interface asserted things that were not true. 3.0 keeps 2.0's breadth and rebuilds every claim so it survives an audit.

2.0  Next.js 16 · Express · MongoDB Atlas · 3 dashboards 3.0  Next.js 15 · Supabase / Postgres · RLS everywhere · 6 role panels · 290+ tests

What went wrong in 2.0

Captured from 2.0's own live deployment. Every badge below is a hardcoded constant — “Optimal” is a string literal, the arrows point up because someone typed an up arrow.

ScreenWhat 2.0 displayed

Everywhere A pulsing green LIVE dot — a CSS animation on a page that fetched once on mount

3.0's first principle: no component may outlive its data. Every number, badge, trend and status pill is derived, or it renders an empty state. A tile with no data shows —, never 0.0 — because zero is a measurement and absence is not. And any number can be expanded to the inputs it was computed from.

That is what a regulator cares about.
